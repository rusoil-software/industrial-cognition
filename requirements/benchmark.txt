# Benchmark-only stack (scripts/benchmark_detectors.py).
#
# Nothing here is installed in the API, the vision worker or the exporter image: this
# file exists so the comparison between candidate detectors can run on a machine with a
# GPU without dragging PyTorch, Ultralytics and their transitive weight into production.
#
# The pins that matter:
#   * torch/torchvision - CUDA build from PyPI on Linux; the benchmark uses fp16 on a GPU
#   * transformers - the same major version the API tokenises with (requirements/api.txt),
#     because Grounding DINO and Florence-2 ride on the same library
#   * ultralytics - YOLO-World, and it is the reason this file is not part of any
#     production image (AGPL-3.0; see src/benchmark/registry.py)
#   * onnxruntime - the CPU path for the incumbent artifact, identical to the cluster
torch>=2.6,<3
torchvision>=0.21,<1
transformers==5.20.1
timm>=1.0
ultralytics>=8.3
# YOLO-World builds its class embeddings with CLIP. Without it ultralytics installs the
# package at import time ("requirements: AutoUpdate"), which cost three minutes inside the
# first measurement and left that model without usable classes. PyPI's ``clip`` stops at
# 0.2.0 and is a different package, so the fork ultralytics itself uses is pinned by URL.
clip @ git+https://github.com/ultralytics/CLIP.git
ftfy>=6.3
accelerate>=1.0
sentencepiece>=0.2
einops>=0.8
# Florence-2 (microsoft/Florence-2-base) ships remote code that imports sentencepiece and
# einops; both are listed above even though neither is used by the other adapters.
opencv-python-headless==4.11.0.86
onnxruntime==1.24.4
numpy<2.0.0
pillow>=11
psutil>=6
